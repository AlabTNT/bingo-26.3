# Bingo! 26.3

A self-contained Bingo engine for Minecraft 26.3 (Fabric).

- Board HUD: top-left, adjustable with `O` or Mod Menu → Bingo! 26.3
- `Y` opens the full card, `H` hides/shows the HUD, `G` opens the lobby screen
- `R` sorts the inventory or the open chest
- Team chest, supply drops, random events, fog boards and hunter mode are configurable with `/bingo`
- 121 advancement missions replace the vanilla advancement tabs
- JEI and ReplayMod are bundled; the self-built minimap (`N`) and world map (`M`) need no external mod
- JEI/map/sorting toggles live in the Bingo settings screen
- Items stack to 128; a chestplate and an elytra can be equipped at the same time

Server owners: use `bingo-26.3-server.zip` and follow its `README.md`.
