# 1. 简介

**Bingo! 26.3** 是面向 Minecraft **26.3（Fabric）** 的自研 Bingo 游戏引擎与整合包。它不依赖 YAMB，棋盘、队伍、大厅、随机地图、任务判定、迷雾、追杀、随机事件、团队仓库、小地图/世界地图与客户端 UI 均由本工程实现。

主要特性：

- 5×5 / 7×7 / 9×9 棋盘，支持 1–4 个棋盘与独立难度。
- 物品 Bingo、进度任务 Bingo、混合模式。
- 每局自动创建新的随机地图维度，无需手动重置世界。
- 服务端权威判定、队伍共享进度、锁定模式、迷雾棋盘。
- 自研小地图与世界地图，按「维度 + 本局随机种子」自动重建。
- 中英文双语、128 堆叠、独立鞘翅槽、ReplayMod、JEI、背包/箱子整理。
- 追杀模式、永昼/永夜、固定天气、补给空投、随机事件、团队仓库。

本说明适用于服主、管理员和普通玩家。命令与配置以 v1.0.0 为准。


# 2. 安装与启动

## 2.1 客户端（推荐 Modrinth 整合包）

1. 安装 **Minecraft 26.3** 与 **Fabric Loader 0.20.1**（或更高兼容版本）。
2. 安装 **Java 25**。
3. 使用 Modrinth App / Prism Launcher / ATLauncher 导入：

   ```text
   dist/Bingo-26.3-1.0.0.mrpack
   ```

4. 启动游戏，进入服务器或单人世界。

整合包已包含：

- Bingo! 26.3 本体
- Fabric API、YACL、Mod Menu
- JEI（配方查看）
- ReplayMod（回放录制）
- Mouse Tweaks
- Lithium、Krypton、C2ME、FerriteCore（性能优化）
- Chunky（区块预生成）
- No Chat Reports

> 小地图与世界地图由本 Mod 自研，不再包含 Xaero。

## 2.2 客户端（手动安装）

将 `dist/mods/` 下的全部 `.jar` 放入 `.minecraft/mods/`，确保使用 Minecraft 26.3 与 Fabric Loader。

## 2.3 服务端

1. 解压：

   ```text
   dist/bingo-26.3-server.zip
   ```

2. 阅读并同意 [Minecraft EULA](https://aka.ms/MinecraftEULA)，将 `eula.txt` 中的 `eula=false` 改为 `eula=true`。
3. 启动：

   ```bash
   ./start.sh        # Linux / macOS
   start.bat         # Windows
   ```

4. 默认端口 `25565`。如需公网访问，请在防火墙/安全组放行。
5. 服务端包只包含服务端必需 Mod：

   - Bingo! 26.3
   - Fabric API
   - Lithium、Krypton、C2ME、FerriteCore
   - Chunky、No Chat Reports

服务端默认 `online-mode=true`；离线测试请自行修改 `server.properties`。

## 2.4 首次启动生成的文件

| 路径 | 说明 |
|------|------|
| `config/bingo-ourselves/server.json` | 服务端玩法配置 |
| `config/bingo-ourselves/client.json` | 客户端 HUD/地图/集成配置（服务端包也会生成一份） |
| `world/bingo/state.json` | 队伍、回合、团队仓库等持久化数据 |
| `world/bingo/elytra.json` | 独立鞘翅槽内容 |
| `world/dimensions/bingo_ourselves/arena/` | Bingo 竞技场维度（每局重建） |


# 3. 快速开始

1. 玩家进入服务器后会被传送到大厅平台。
2. 使用大厅物品或命令加入队伍：

   ```text
   /bingo join red
   ```

3. 准备好后按 `T` 输入：

   ```text
   /bingo ready
   ```

   或右键大厅中的“准备”钟。

4. 所有队伍准备且人数达到 `minPlayers` 后，自动倒计时 10 秒。
5. 管理员也可以直接开始：

   ```text
   /bingo start
   /bingo start force    # 跳过人数检查
   ```

6. 对局开始后：

   - 每队被传送到竞技场中相隔一定距离的出生点。
   - 自动创建新的随机地图维度。
   - 生成棋盘、清空本轮进度、给予初始物品/鞘翅。
   - 收集物品或完成进度任务即可点亮格子。

7. 达成目标（默认完成 1 条连线）即获胜。结算 15 秒后回到大厅。


# 4. 游戏规则

## 4.1 棋盘

默认 5×5。每个格子是一个**物品目标**或**进度任务**：

- 物品目标：队伍中任意成员背包里出现该物品即完成。
- 进度任务：队伍中任意成员完成对应进度即完成。
- 完成判定在服务端每 0.5 秒扫描一次。

棋盘可通过命令或配置文件调整：

| 配置 | 可用值 | 默认 |
|------|--------|------|
| 尺寸 | 3 / 5 / 7 / 9 | 5 |
| 棋盘数量 | 1–4 | 1 |
| 目标池 | `items` / `advancements` / `mixed` | `mixed` |
| 难度 | `easy` / `medium` / `hard` / `extreme` / `custom` | `easy` |
| 胜利条件 | `lines` / `items` / `cards` | `lines` 1 |

## 4.2 难度分布

难度决定 S/A/B/C/D 各档格子的数量。5×5 默认分布：

| 难度 | S | A | B | C | D |
|------|---|---|---|---|---|
| easy | 0 | 0 | 0 | 9 | 16 |
| medium | 0 | 0 | 3 | 10 | 12 |
| hard | 0 | 1 | 5 | 10 | 9 |
| extreme | 0 | 5 | 7 | 7 | 6 |

其他尺寸会按格子总数等比缩放；也可以使用 `/bingo distribution` 自定义。

## 4.3 胜利条件

- `lines N`：先完成 N 条横线/竖线/对角线。
- `items N`：先完成 N 个格子。
- `cards N`：先完成 N 张完整棋盘。

## 4.4 锁定模式（Lockout）

`/bingo lockout on` 后，某个格子被一支队伍完成后即归该队所有，其他队伍无法再得分。

## 4.5 迷雾棋盘

`/bingo fog on` 后：

- 初始只揭示中心若干格。
- 完成一个格子会揭示其上下左右相邻格。
- 未揭示的格子显示为 `?`。
- 服务端仍会检测隐藏格子的完成情况，不会漏判。

## 4.6 多棋盘

`/bingo boards 2` 可生成多张棋盘，队伍按顺序分配。每张棋盘可单独设置难度：

```text
/bingo board 1 difficulty easy
/bingo board 2 difficulty hard
```

# 6. 客户端界面与按键

## 6.1 按键

| 按键 | 功能 |
|------|------|
| `Y` | 打开棋盘详情页 |
| `H` | 隐藏 / 显示棋盘 HUD |
| `O` | 打开 Bingo 设置（YACL） |
| `G` | 打开大厅界面 |
| `R` | 整理背包 / 当前打开的箱子 |
| `M` | 打开自研世界地图 |
| `N` | 隐藏 / 显示自研小地图 |

所有按键都可以在“选项 → 控制 → 按键绑定”中重新设置。若 `R` 与其他 Mod 冲突，可改键。

## 6.2 棋盘 HUD

默认位于左上角，显示：

- 5×5（或配置尺寸）棋盘与物品图标。
- 本队已完成格子的绿色覆盖。
- 锁定模式下其他队伍拥有的格子边框。
- 迷雾模式下未揭示格子的 `?`。
- 回合剩余时间。

可在 `O` 设置中调整：开关、角落、偏移、缩放、背景、透明度、计时器、F3 隐藏、聊天时隐藏。

## 6.3 棋盘详情页

按 `Y` 打开。显示更大的棋盘、计时器、进度条和各队得分；鼠标悬停可查看目标名称与完成状态。

## 6.4 自研小地图

- 默认位于右上角，默认 96 像素、2 格/像素。
- 直接采样客户端已加载区块，不需要任何外部地图 Mod。
- 显示玩家位置、北向标记和坐标。
- 按 `N` 快速开关；`O` 中可调角落、尺寸、透明度、北向朝上。

## 6.5 自研世界地图

- 按 `M` 打开。
- 鼠标拖拽平移，滚轮缩放（1–32 格/像素）。
- 显示玩家位置、当前中心坐标和缩放比例。
- 地图缓存以「维度 + 本局随机种子」为键；**每局开始会自动清空并重建，不需要手动删除/添加地图。**
- 只显示已加载/探索过的区域；未加载区域为深色。

## 6.6 大厅界面

按 `G` 打开：选择队伍、准备、管理员开始对局。也可以直接使用大厅物品：

- 指南针：循环切换队伍
- 钟：准备
- 地图：打开棋盘
- 箱子：团队仓库
- 书：大厅界面

# 8. 玩法扩展

## 8.1 追杀模式

```text
/bingo preset hunter
/bingo start
```

规则：

- 最后一个非空队伍（或 `extras.hunterTeam` 指定队伍）成为猎人。
- 其余队伍为跑者，默认 3 条命。
- 跑者死亡扣 1 条命；生命耗尽后变为旁观者。
- 猎人每秒收到最近跑者的距离与方向提示。
- 跑者完成 Bingo 则跑者获胜；所有跑者出局则猎人获胜；时间结束且无人 Bingo 则猎人获胜。

可用 `/bingo hunter on|off` 单独开关。

## 8.2 天气与昼夜

```text
/bingo weather clear
/bingo weather rain
/bingo weather thunder
/bingo daylight day
/bingo daylight night
/bingo daylight cycle
```

## 8.3 补给空投

默认每 5 分钟在每队附近生成一个装有战利品的箱子；也可以手动触发：

```text
/bingo supply
```

## 8.4 随机事件

默认每 3 分钟随机触发：

- 怪物潮
- 物品雨
- 随机传送
- 随机状态效果

手动触发：

```text
/bingo event mobs
/bingo event rain
/bingo event teleport
/bingo event effects
/bingo event random
```

## 8.5 团队仓库

```text
/bingo chest
```

打开本队 27 格共享箱子；内容在对局结算和服务器关闭时持久化。

## 8.6 独立鞘翅槽

在玩家背包界面右侧新增一个鞘翅槽（x=152, y=62）：

- 胸甲继续装备在胸甲槽。
- 鞘翅放入独立槽后即可滑翔。
- 两个装备的效果同时生效。
- 配置 `game.elytra=true` 时，开局自动把鞘翅放入该槽。

> 未安装本 Mod 的原版客户端看不到该槽。


# 9. 进度任务与数据

本工程用自带进度树替换原版可见进度：

- 5 个标签页：故事、下界、末地、冒险、农牧业。
- 121 个任务，按原版进度列表实现。
- 原版五个可见进度目录通过数据包过滤器屏蔽；配方解锁进度保留，避免配方书失效。
- 每局开始会重置本模组进度的完成状态。

相关文件：

| 路径 | 内容 |
|------|------|
| `data/bingo_ourselves/advancement/` | 121 个任务 + 5 个标签页根 |
| `data/bingo_ourselves/bingo/advancements.json` | 进度任务池与难度档 |
| `data/bingo_ourselves/bingo/items.json` | 物品任务池与难度档 |

重新生成工具（开发者）：

```bash
python3 tools/generate_advancements.py ...
python3 tools/generate_objectives.py ...
```


# 10. 集成与性能

## 10.1 JEI

整合包携带 JEI。设置 `O → Integrations → JEI overlay` 可隐藏/显示 JEI 覆盖层。

## 10.2 背包与箱子整理

- 打开背包或箱子，按 `R`。
- 服务端合并同类物品、按物品 ID 排序并同步。
- 可在 `O → Integrations → Inventory sorting` 关闭。

## 10.3 ReplayMod

# 11. 常见问题

**Q：客户端没有棋盘 HUD？**  
A：确认客户端和服务端都安装了 Bingo! 26.3；按 `H` 检查是否被隐藏；按 `O` 检查 `Show board HUD`。

**Q：小地图/世界地图是空的？**  
A：地图只采样已加载区块。移动探索后会自动填充；服务器视距太小时远处会保持深色。

**Q：新一局地图还显示上一局？**  
A：地图缓存按「维度 + 本局随机种子」区分，新一局会自动清空；如果未刷新，确认服务端已开始新回合并收到状态同步。

**Q：服务端启动报动态维度创建失败？**  
A：本 Mod 会记录错误并自动回退到固定维度 + 随机区域。功能仍可用，但不同回合可能共用维度文件夹；可查看 `logs/latest.log`。

**Q：为什么原版进度不见了？**  
A：这是需求 10：原版五个可见进度标签页被替换为 121 个 Bingo 任务；配方解锁进度仍保留。

**Q：`R` 键与别的 Mod 冲突？**  
A：在“选项 → 控制 → 按键绑定 → Bingo! 26.3”中改键。

**Q：鞘翅槽在哪里？**  
A：打开背包，右侧独立槽位（x=152, y=62）；把鞘翅拖进去即可，胸甲不会被替换。

**Q：如何完全关闭某个集成？**  
A：JEI 覆盖层、小地图、世界地图、整理均可在 `O` 设置中关闭；ReplayMod 使用其自身设置。

**Q：如何重置所有配置？**  
A：停止服务器，删除 `config/bingo-ourselves/` 后重启；玩家队伍/仓库数据在 `world/bingo/state.json`。
